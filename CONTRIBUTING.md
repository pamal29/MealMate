# Contributing

- Never push directly to `main`. Open a pull request.
- Branch names: `feature/<module>-<desc>`, `fix/<desc>`, `docs/<desc>`
- Commit style: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`
- Every PR needs at least 1 review before merging (squash merge).
- Pull the latest `main` before starting work.
- Never commit `.env` or Firebase key files.
